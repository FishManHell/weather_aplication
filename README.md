# Weather App

Weather App is a frontend application for searching and tracking weather conditions in different cities.  
It provides current weather details, hourly forecast, and a favorites feature in a clean and user-friendly interface.

---

## Overview

The project was built as a weather tracking application focused on simplicity, clear data presentation, and convenient city search.  
It allows users to view current weather information, switch temperature units, and save favorite locations for quick access.

---

## Features

- Search weather by city name
- Display current weather conditions
- Show hourly forecast
- Save and manage favorite locations
- Switch between Celsius and Fahrenheit
- Geolocation support
- Responsive interface
- Loading and error state handling
- Test coverage for key parts of the application

---

## Main Pages

- **Today** — current weather details and hourly forecast
- **Favorite** — saved cities with quick weather overview
